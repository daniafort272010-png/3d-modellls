Conversion / changes for the external runtime payload:
- Unity coordinate and UV conversion; normalized height to 1.8 model units.
- Converted the 58-joint skin to 19 runtime controls; fingers/toes follow wrists/feet.
- Solid log torso weights were merged to the chest to prevent face/body stretching.
- Upper-arm weights along the cylinder were moved to the torso; the visible arm tubes
  were split smoothly into upper/lower arm controls to correct source attachment pivots.
- Separate runtime skeleton preserves Sahur's proportions while following game poses.
No model geometry or texture is embedded in the DLL.
